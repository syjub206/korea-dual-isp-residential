## 双ISP住宅IP、原生IP、机房IP，到底差在哪

这三个词经常被混着用，但说的是不同的事。

**原生IP** 指的是 IP 的 whois 和地理数据库里，归属地和 ISP 名称就是韩国本土运营商的真实信息，不是广播过去的段。平台一查，登记的是韩国用户。

**DNS 解锁** 是另一回事：IP 本身没变，靠解析层面把特定请求导到解锁节点。便宜，但平台识别的概率高，做长期账号不踏实。

**单 ISP 和双 ISP** 的区别在于，单 ISP 的 IP 只挂在一个运营商名下，双 ISP 是同时关联两个 ISP 归属。真实家庭宽带经常是多线接入，所以双 ISP 在风控模型里更接近"真人住的房子"。做 TikTok 这类对 IP 环境极其敏感的平台，双 ISP 的抗封能力更强，价格也更贵。

线路代号顺带说清楚：CN2 GIA 是电信的高端线路，9929 是联通高端，4837 是联通中间档，CMI 是移动国际。商家标"三网优化"通常意思是三家回程都走了优化路由，但具体到某一台机器，宣传口径和实际路由经常对不上，还是得看实测。

所以判断一台韩国双ISP住宅IP值不值得买，看五件事：

1. IPinfo 或 MaxMind 查出来是不是 Residential
2. 是不是静态 IP（长期同一地址，账号不跳）
3. 回程路由是直连，还是绕欧洲、绕美国
4. 带宽和流量跟你的业务对不对得上
5. CPU 能不能扛住你要跑的东西

LisaHost 官方页面写的是"三网优化网络，三网延迟低"。但第三方实测结果不是这样：只有移动和教育网真的好，电信联通是绕路的。这个差异后面会详细拆。
